# Campus Placement & Internship Pipeline

## Overview

The Campus Placement & Internship Pipeline is a system designed to manage the campus placement and internship application process for students and placement officers.

## Project Scope

The system supports:
- Viewing active placement and internship drives
- Applying for drives
- Uploading and parsing resumes
- Checking student eligibility
- Viewing eligibility discrepancies
- Managing interview queues and processes
- Processing offer letters
- Tracking application status

## Actors

- **Student Applicant** – views drives, applies for opportunities, uploads resumes, and tracks application status.
- **Placement Officer** – manages interview queues, interview processes, and offer letters.
